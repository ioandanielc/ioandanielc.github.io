# ioandanielc.github.io

Personal site, built by GitHub Pages (Jekyll).

- `index.html`: homepage
- `cv.pdf`: CV
- `_posts/`: published blog posts, named `YYYY-MM-DD-slug.md`
- `_drafts/`: unpublished drafts (not built on GitHub Pages)
- `assets/style.css`: shared styles; `assets/img/`: images for posts

Write a post: copy `_drafts/post-template.md`, edit, move to `_posts/` with a dated filename, commit.
Set `math: true` in a post's front matter to enable LaTeX via KaTeX.
The Blog link on the homepage appears automatically once `_posts/` contains at least one post.
